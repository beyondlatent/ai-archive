컨설팅사만 보면 편향이 생기므로 성격이 다른 기관을 함께 봅니다.

| 성격 | 기관 |
| --- | --- |
| 컨설팅 | McKinsey · BCG · Deloitte |
| 회계·컨설팅 | PwC · KPMG · EY |
| 리서치 | Gartner |

| 국제기구 | World Economic Forum |

| 벤처캐피털 | Menlo Ventures |

기관에 따라 같은 질문의 답이 크게 달라집니다. 'AI로 성과를 낸 조직' 비율이 **5%에서 97%까지** 벌어지고, 특히 AI 제품이나 인프라를 파는 기업의 조사에서 수치가 일관되게 높습니다. 자세한 비교는 [통합 전망 글](docs/posts/2025-2026-enterprise-ai-adoption-research.html)에 있습니다.
